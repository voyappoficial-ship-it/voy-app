### 📋 Pasos para la instalación:
1. Haz clic en el enlace de descarga o escanea el código QR desde tu teléfono.
2. Si tu navegador te pregunta *"¿Deseas descargar este archivo?"*, presiona **Descargar de todos modos**.
3. Una vez terminada la descarga, abre el archivo Voy.apk.
4. Si el sistema te lo solicita, activa el permiso de **"Instalar aplicaciones de fuentes desconocidas"** para tu navegador.
5. Presiona **Instalar** y ¡listo! Abre la aplicación y regístrate como pasajero o conductor.
